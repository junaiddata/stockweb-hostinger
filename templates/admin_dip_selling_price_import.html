  • Needs the columns Item No. and SELLING PRICE (any letter case; the header row can be row 1 or 2).
  • Only items that already exist in DIP are updated. Others are skipped and listed.
  • Stock, cost, description and manufacturer are not changed.
  • Prices are saved like the Min. Selling Price edit button, so admins can still edit them later and the stock sync will not remove them.

Tip: use Preview first to check the counts, then choose the file again and press Apply.
