Excel Format Required:
  • ItemCode - Item code (required)
  • CostPrice - Cost price (required)

ℹ️ How It Works

When API sync runs:
  • Items with overrides use YOUR uploaded cost price
  • API cost price is IGNORED for these items
  • Selling price is calculated based on override cost + margin
  • Other items use API cost price as normal
⚠️ Temporary Solution:

Once SAP is updated with correct cost prices, you can remove all overrides and the system will use API data again.
